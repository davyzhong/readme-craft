# 项目归档入口

本目录保存 readme-craft 已交付产品的公开、可长期阅读的静态记录。归档以 2026-09-25 为审查快照；事实以对应版本源码、规则和 Git 标签为准。

## 导航

- [项目演进史](project-history.md)：目标、产品形态与关键阶段。
- [2026-09-25 全面审查](2026-09-25-review.md)：内部审查、竞品地图、缺口清单与冻结结论。
- [中期冻结标准](mid-cycle-freeze-standard.md)：今后每次中期冻结的强制工作流及验收标准。
- [当前权威计划](../plans/2026-09-25-midcycle-freeze-review.md)：本次审查的范围、进度、决策与验证记录。

## 公开与私有资料

公开归档仅保留可公开的项目级决策、时间线和证据链接。内部仓库名、个人本地路径、内部审计原文及私有项目样例留在被 `.gitignore` 排除的 `.local/archive/`。私有归档索引记录原始资料清单与边界；它不会随公开仓库发布。Git 历史本身也有独立的私有存档，公开历史是否还需进一步净化属于仓库所有者决策，本文不复制其敏感内容。

## 快照边界

竞品能力与项目状态会变化。本快照注明日期，并链接一手来源；读者应在采取发布、依赖或市场决策前复核来源。无法从当前仓库或可访问 Git 引用验证的事项均标作待确认。
